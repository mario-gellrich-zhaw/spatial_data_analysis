Method & Data

Step-by-step explanation of the GCN-based geodemographic classification pipeline, following De Sabbata & Liu (2023).

1

What is geodemographic classification?

Geodemographic classification groups geographic areas by socio-economic similarity. Traditional methods such as K-Means treat each area independently. Graph Neural Networks (GNNs) go further by incorporating spatial neighbourhood structure: a municipality's representation is shaped not only by its own features, but also by those of its neighbours.

This matters because neighbouring areas often share infrastructure, labour markets, and cultural characteristics — patterns that attribute-only clustering misses. De Sabbata & Liu (2023) proposed the first GNN framework designed specifically for this task.

2

Study area and data

Boundaries: 162 municipalities in Kanton Zürich, Switzerland (swisstopo GeoJSON, EPSG:4326). Each municipality is identified by its BFS number (Bundesamt für Statistik).

Features: Four socio-economic attributes from BFS municipal statistics, joined to the GeoJSON by BFS number:

FeatureBFS variableNotes
Mean taxable income (kCHF)mean_taxable_incomeMean taxable income per taxpayer (BFS: pro Steuerpflichtigen/-r)
Population density (/km²)pop_densInhabitants per km²
Share of foreign residents (%)frg_pctPercentage of non-Swiss residents
Employment rate (%)emp / pop × 100Jobs per 100 residents; values > 100 indicate net job importers

Missing values (5 municipalities for income, 4 for employment) are imputed from the mean of the 5 spatially nearest municipalities that have a valid value for that variable.

3

Spatial graph construction

Spatial relationships are encoded as an undirected graph G = (V, E):

  • Nodes V — one per municipality (|V| = 162)
  • Edges E — an edge (i, j) is added if municipalities i and j share ≥ 2 boundary coordinate pairs, i.e. they have a common border segment (Queen's-case contiguity)

The resulting planar graph has roughly 400 edges and a mean degree of ~5. You can inspect it in the Graph tab. After clustering, within-cluster edges are highlighted in the cluster colour.

4

Normalised adjacency matrix

To stabilise gradient flow, the adjacency matrix is augmented with self-loops and symmetrically normalised (Kipf & Welling, 2017):

Â = D̂−½ (A + I) D̂−½

where A is the binary adjacency matrix, I is the identity (self-loops preserve each node's own features during aggregation), and D̂ is the diagonal degree matrix of (A + I). The symmetric normalisation prevents nodes with many neighbours from dominating the update.

5

Each GCN layer applies a graph-aware linear transform:

H(l+1) = ReLU( Â · H(l) · W(l) )

Multiplying by Â aggregates (averages) the feature vectors of each node's neighbours before applying the weight matrix — this is the message-passing step.

Number of message-passing layers controls how wide the spatial context window is:

LayersNeighbourhood reachedEffect
0Node itself onlyEquivalent to K-Means on raw features — no spatial context
1Direct neighbours (1-hop)Each embedding reflects own features + immediate border municipalities
2 (default)2-hop neighbourhoodContext spans ~2 municipal boundaries; good balance
3+3-hop and beyondRisk of over-smoothing: embeddings converge as every node sees a large, similar neighbourhood — analogous to blurring an image too many times

Training: MSE loss between X̂ and the standardised input X, minimised with SGD + momentum (lr = 0.015, momentum = 0.9, 400 epochs). No class labels are used — this is fully unsupervised.

6

K-Means clustering on the embeddings

After training, the 8-dimensional node embeddings Z encode both socio-economic similarity and spatial neighbourhood context. K-Means (k = 5, 20 random initialisations) is applied to Z to produce the final geodemographic segments.

Because Z has been shaped by message passing, municipalities that are both attributally similar and spatially proximate cluster together more coherently than standard K-Means on raw features. The JS version in this app omits the training loop (fixed random weights) and is therefore a fast approximation; the Python version trains fully.

Student Exercises

Work through the exercises in the interactive lab. Use the Map, Graph, and Scatter tabs to explore the results. All exercises can be completed in the browser — no coding required unless marked ★.

1
Run the GNN and explore the map
Basic
  • Click ▶ Run Python GNN. The map colours 162 municipalities into 5 geodemographic clusters.
  • Click on any municipality. Read its feature values and cluster profile in the sidebar. Do the values match the visual impression of the cluster on the map?
  • Switch to the Graph tab. Edges between municipalities in the same cluster are coloured; cross-cluster edges are grey.
  • Do municipalities that share an edge tend to be in the same cluster? Find two counter-examples where they are not, and suggest why.
Tip: drag nodes in the Graph tab to untangle the layout. The initial positions are seeded from geographic coordinates.
2
Interpret and label the geodemographic segments
Basic
  • Read the five cluster profile cards in the sidebar. For each cluster note its mean income, population density, share of foreign residents, and employment rate.
  • Assign a descriptive label to each cluster, e.g. urban core, affluent lakeside, working-class suburban, small town, rural peripheral.
  • Click on the city of Zürich on the map. Which cluster does it belong to? Does the profile match your expectations?
  • Find at least one municipality whose cluster assignment surprises you. How do you explain it?
Hover over any municipality on the map to see its individual feature values alongside the cluster average.
3
Explore feature distributions in the scatter plot
Basic
  • Switch to the Scatter tab. The axes show two features; points are coloured by cluster.
  • Which pair of features produces the clearest cluster separation? Which pair overlaps the most?
  • Click a point in the scatter plot to highlight the same municipality on the map. Find a municipality that is an outlier in the scatter plot but centrally located on the map — how do you explain the discrepancy?
  • Which feature do you think contributes most to the urban–rural split visible on the map? Justify your answer using the scatter plot.
4
Spatial coherence of clusters
Intermediate
  • In the Graph tab, enable Show names. Count how many municipalities in the largest cluster are isolated (surrounded only by nodes of a different cluster).
  • The GCN aggregates each node's features with its neighbours before clustering. Would you expect more or fewer isolated nodes if the model used the raw features without any graph convolution? Explain your reasoning.
  • Read Step 5 (Message-passing layers) on the Method page. What happens to cluster coherence when the number of layers is very large? What is this phenomenon called?
Over-smoothing: with many layers every node aggregates an increasingly large neighbourhood, eventually causing all embeddings to converge — analogous to blurring an image too many times.

Adjacency graph degree and cluster membership
Intermediate

  • Find the municipality with the highest degree. Look up its geographic position on the map. Does its location explain its high connectivity?
  • In a GCN, a high-degree node aggregates many neighbours during message-passing. How might this affect its embedding compared to a low-degree node?

7
Critical evaluation — limitations and extensions ★
Advanced
  • Feature selection: The model uses four BFS variables. What additional socio-economic or environmental features would you include? Consult the Swiss Federal Statistical Office (BFS) website for ideas.
  • Number of clusters: k = 5 is fixed. How would you choose k objectively? Describe one internal validation measure (e.g. silhouette score) and explain what it measures.
  • Validation: No ground-truth geodemographic labels exist. Propose two methods for evaluating the quality of the classification — one internal (using only the data) and one external (using an independent source).
  • Loss function: The autoencoder uses MSE reconstruction loss. Is this the right objective for geodemographic classification? What alternative training objectives could be used?
★ These questions require written reflection (no browser interaction needed). Suitable as a homework or seminar task.
